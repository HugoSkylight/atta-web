Atta / Security

Security

This page covers the public website. It is not a security assessment of the Atta product.

Scope

The site is static HTML, CSS, and JavaScript. It has no application backend, login, database, user accounts, payments, file uploads, forms, or text inputs.

Source and dependencies

The full website source is in the public repository. The site loads one third-party resource, the Jost font from Google Fonts. The official site is hosted on Cloudflare. A GitHub Pages copy of the repository may also be available.

What this page does not claim

No audit, certification, or bug bounty is published. Nothing here is a claim about the security of the Atta product, its encryption, logging, model training, or data retention. Those properties depend on a deployment, and the product code is not public.

Reporting a problem

Open an issue in the website repository for website problems. Do not include exploit details, credentials, personal data, or other secrets in a public issue.

No private security contact or encryption key is published. If a report needs a private channel, open an issue without sensitive details and ask the maintainer how to proceed.

Supported version

The website has no versioned releases. Its published source history is available in the website repository.
