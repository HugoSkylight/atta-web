Atta / 隐私

隐私

本政策覆盖公开的 Atta 网站。它不描述 Atta 产品或任何产品部署。

本站收集什么

网站没有账户、表单、评论、邮件订阅、支付、分析脚本、广告或追踪像素，也没有应用后端。托管方和字体提供方会接收下文所述的浏览器请求。

Cookie 与本地存储

网站代码不设置 Cookie，也不保存语言偏好。每种语言都有独立 URL。刷新页面或沿本站导航访问时，网址会保留所选语言。

第三方请求

本站从 Google Fonts 加载 Jost 字体。浏览器连接 fonts.googleapis.com 和 fonts.gstatic.com 时，会分享 IP 地址和浏览器请求头等连接信息。来源信息取决于浏览器策略。参见 Google 隐私政策。

正式站托管在 Cloudflare 上。Cloudflare 可能为交付网站和保护服务处理请求信息。本页不指定 Cloudflare 的日志和保留设置。参见 Cloudflare 隐私政策。

本站副本也可能仍通过公开仓库的 GitHub Pages 提供。若该副本仍可访问，GitHub 按其GitHub 隐私声明处理请求；本页不指定 GitHub 的设置。

指向 GitHub 和其他网站的链接会离开本站。那些网站适用各自的政策。

联系

问题和更正请发到网站仓库的 Issues。Issues 是公开的，请不要包含个人数据或机密。没有公布公开电子邮箱。

变更

本政策可能随网站变化。更新日志记录网站的变化。
