项目与可用性

Atta 是一个自托管 AI 工作台的概念。本页说明公开网站展示了什么、怎样理解交互演示，以及今天能得到什么、不能得到什么。

Atta 是什么

Atta 是一个自托管 AI 工作台的概念。它把运行在不同机器上的 Agent 放进一张实时图。每条流程有若干步骤，每个步骤属于一个 Agent；发布、付款、删除这类危险步骤会停在名为 Hodor 的门前，等所有者批准。

名字来自切叶蚁。设计面向一个人指挥一支小型 Agent 团队，而不是盯着许多终端。

本站展示的是概念，不是运行中的产品实例。

演示展示了什么

首页演示是带示例数据的脚本化交互。周报、三台机器、Bot、分数和版本都是示例，不是实时数据。

你可以点步骤、切换流程、批准门禁，并观察自我改进循环。演示在浏览器里运行，不向服务器发送任何内容。

自我改进面板模拟设想的循环：只改一条规则，用同一组评测用例重跑，只有分数上升且所有者批准，改动才保留。

可用性

Atta 尚未公开。本站不提供下载、安装包、托管服务、账户或注册，也不提供公开安装说明。

公开仓库包含什么

公开的 GitHub 仓库包含这个网站：HTML、CSS、JavaScript、图片和这些页面的生成脚本。它不包含产品实现，也没有发布产品许可证。
