Atta / 安全

安全

本页覆盖公开网站。它不是对 Atta 产品的安全评估。

范围

本站是静态 HTML、CSS 和 JavaScript，没有应用后端、登录、数据库、用户账户、支付、文件上传、表单或文本输入框。

源码与依赖

完整的网站源码在公开仓库中。本站只加载一个第三方资源，即来自 Google Fonts 的 Jost 字体。托管方是 GitHub Pages。

本页不声明什么

没有公布审计、认证或漏洞赏金。本页不声明 Atta 产品的安全性、加密、日志、模型训练或数据保留。这些属性取决于具体部署，产品代码不公开。

报告问题

网站问题请在网站仓库开 Issue。不要在公开 Issue 中包含漏洞细节、凭据、个人数据或其他机密。

没有公布私有安全联系人或加密密钥。如果报告需要私下渠道，请先开一个不含敏感细节的 Issue，询问维护者如何继续。

支持的版本

网站没有版本化发布。已发布源码的历史可在网站仓库查看。
