Atta / Project and availability

Project and availability

Atta is a self-hosted AI workbench concept. This page explains what the public site shows, how to read the interactive demos, and what you can and cannot get today.

What Atta is

Atta is a self-hosted AI workbench concept. It puts agents that run on different machines into one live map. Each flow has steps, each step belongs to an agent, and risky steps stop at a gate called Hodor until the owner approves them.

The name comes from the leafcutter ant. The design targets one person who directs a small team of agents instead of watching many terminals.

This site presents the concept. It is not a live product instance.

What the demos show

The home page demos are scripted interactions with sample data. The weekly report, the three machines, the bots, the scores, and the versions are examples. They are not live data.

You can click steps, switch flows, approve the gate, and watch the self-improvement loop. The demos run in your browser and send nothing to a server.

The self-improvement panel simulates the proposed loop. One rule changes, the same eval cases run again, and the change stays only if the score rises and the owner approves it.

Availability

Atta is not publicly available. This website offers no download, installer, hosted service, account, or sign-up. It does not provide public installation instructions.

No public release date is published.

What the public repository contains

The public GitHub repository contains this website: HTML, CSS, JavaScript, images, and the generator for these pages. It does not contain the product implementation, and no license for the product is published.

Contact

Use the website repository issues for questions and corrections. The maintainer is Hugo Light. No public email address is published.

Issues are public. Do not post API keys, tokens, private logs, customer data, or other secrets. The maintainer can correct errors in this site. Product support is not offered through this site.
