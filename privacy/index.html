Atta / Privacy

Privacy

This policy covers the public Atta website. It does not describe the Atta product or any deployment of it.

What the site collects

The website has no accounts, forms, comments, newsletter, payments, analytics scripts, advertising, or tracking pixels. It has no application backend. Hosting and font providers receive browser requests as described below.

Cookies and local storage

The website code sets no cookies and stores no language preference. Each language has its own URL. Your chosen language stays in the URL when you refresh or follow the site's navigation.

Third-party requests

The site loads the Jost font from Google Fonts. Your browser connects to fonts.googleapis.com and fonts.gstatic.com and shares connection information such as your IP address and browser headers. Referrer information depends on your browser's policy. See the Google Privacy Policy.

The official site is hosted on Cloudflare, which may process request information to deliver the site and protect the service. This page does not specify Cloudflare's logging or retention settings. See the Cloudflare Privacy Policy.

A copy of this site may also be available through GitHub Pages from the public repository. If that copy remains reachable, GitHub handles those requests under the GitHub Privacy Statement; this page does not specify GitHub's settings.

Links to GitHub and other sites leave this site. Those sites apply their own policies.

Contact

Questions and corrections go to the website repository issues. Issues are public, so do not include personal data or secrets. No public email address is published.

Changes

This policy may change with the site. The changelog records changes to the website.
